# kavarna-flask

Webová stránka kavárny vytvořená ve Flasku s titulní stranou a kontaktní stranou


## Vytvoření virtuálního prostředí

```shell
python -m venv .venv
```

`-m` python modul - zde se jmenuje `venv`

`.venv` název adresáře s virtuálním prostředím

## Aktivace prostředí

```shell
.venv\Scripts\activate.bat
```

## Instalace frameworku Flask

```shell
pip install Flask
```

## Spuštění aplikace

Výchozí soubor s aplikací se jmenuje `index.py` .

```shell
flask --app index run --debug
```
